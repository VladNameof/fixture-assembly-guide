# Инструкция по сборке фикстуры Compute Shelf

Интерактивная 3D инструкция по сборке производственной фикстуры для шасси Compute Shelf из труб Lean Pipe Ø28 мм на зажимах HJ-2 (2 шт. 3D-угол) и HJ-1 (10 шт. Т-стык).
